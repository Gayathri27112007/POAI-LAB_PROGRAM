# EXPERIMENT 2 – AGENT ENVIRONMENTS

## Aim
To study different types of environments in which intelligent agents operate.

## Introduction
An agent environment is the surrounding world in which an intelligent agent receives information and performs actions.

## 1. Fully Observable Environment

An environment is fully observable when the agent can access all the information required to make a decision.

**Example:** Chess, where all pieces and their positions are visible.

## 2. Partially Observable Environment

An environment is partially observable when the agent cannot access complete information about the environment.

**Example:** A self-driving car cannot directly know every hidden obstacle or another driver's intention.

## 3. Known Environment

An environment is known when the agent understands the rules and outcomes of its actions.

**Example:** A chess program knows the legal moves and rules of chess.

## 4. Unknown Environment

An environment is unknown when the agent does not initially know all the rules or outcomes and must learn them.

**Example:** A robot exploring an unfamiliar area.

## 5. Static Environment

An environment is static when it does not change while the agent is making a decision.

**Example:** A crossword puzzle.

## 6. Dynamic Environment

An environment is dynamic when it can change while the agent is making a decision.

**Example:** A self-driving car operating on a busy road.

## 7. Discrete Environment

An environment is discrete when it has a limited or countable number of states and actions.

**Example:** Chess, where moves and board positions are represented by distinct states.

## 8. Continuous Environment

An environment is continuous when states or actions can take any value within a range.

**Example:** A robot controlling its speed and movement.

## 9. Deterministic Environment

An environment is deterministic when an action produces a predictable result.

**Example:** Moving a chess piece according to the rules.

## 10. Stochastic Environment

An environment is stochastic when an action may produce different outcomes due to uncertainty or randomness.

**Example:** A robot moving on a slippery surface.

## 11. Episodic Environment

An episodic environment divides activities into separate tasks. Each decision is independent of previous decisions.

**Example:** An image classification system classifying individual images.

## 12. Sequential Environment

A sequential environment is one where the current action affects future states and decisions.

**Example:** Playing chess, where every move affects the next move.

## Comparison

| Environment | Meaning |
|---|---|
| Fully Observable | Complete information |
| Partially Observable | Incomplete information |
| Known | Rules are known |
| Unknown | Rules or outcomes must be learned |
| Static | Does not change during decision-making |
| Dynamic | Changes during decision-making |
| Discrete | Countable states |
| Continuous | Values vary continuously |
| Deterministic | Predictable outcome |
| Stochastic | Uncertain outcome |
| Episodic | Independent tasks |
| Sequential | Actions affect future decisions |
